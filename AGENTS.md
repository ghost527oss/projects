# Project engineering rules

- Scope: implement Person 1 tasks from the supplied urban water-management plan. Do not add Person 2 application work without approval.
- Inspect existing code and documentation, then explain intended changes and risks before editing.
- Every function, including tests, must have a docstring describing purpose, approach, inputs and outputs.
- Preserve existing interfaces; keep changes focused and dependencies minimal.
- Validate inputs, expose errors, protect secrets, and do not fabricate data or model results.
- Run relevant tests and report actual results, limitations and decisions required.
- Document methods, units, coordinate systems, provenance and assumptions.
